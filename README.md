# ⚡ Fetcher — Dev API Gateway & CORS/Cookie Resolver

Шлюз и умный прокси для решения проблем **CORS** и передачи **Cookie / Сессий** при запуске фронтенда и бэкендов в разных Docker-контейнерах или портах.

---

## 🎯 В чём была проблема?
* **CORS ошибки**: браузер блокирует запросы между разными портами или доменами (`localhost:3000` -> `localhost:8000`), если бэкенд не настроен на CORS или не возвращает правильные заголовки на preflight-запросы `OPTIONS`.
* **Потеря Cookie / Сессий**: при кросс-доменных запросах или локальной разработке по `http://`, браузер отклоняет куки с флагом `Secure`, а также куки с чужим `Domain`.

## 💡 Как Fetcher это решает?
1. Вы запускаете приложение `Fetcher` и вводите URL реального бэкенда (например, `http://localhost:8000` или `http://api-container:8080`).
2. Приложение выделяет локальный порт (например, `http://localhost:5001`).
3. Во фронтенде (в `.env`) вы указываете адрес прокси:
   ```env
   VITE_API_URL=http://localhost:5001
   ```
4. **Fetcher автоматически**:
   * Перехватывает preflight-запросы `OPTIONS` и мгновенно возвращает `204 OK`.
   * Зеркалирует `Origin` фронтенда в `Access-Control-Allow-Origin` и разрешает `Credentials: true`.
   * Очищает `Secure` для локального HTTP и адаптирует `Domain` в `Set-Cookie`.
   * Проксирует WebSocket соединения.
   * Логирует весь трафик в реальном времени с подсветкой изменений.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
cd client && npm install && npm run build && cd ..
```

### 2. Запуск приложения
```bash
npm start
```
Панель управления будет доступна по адресу: **[http://localhost:4000](http://localhost:4000)**

*(Для режима разработки с горячей перезагрузкой клиента и сервера используйте `npm run dev`)*.

## 🖥 Панель управления (Dashboard)

В веб-интерфейсе доступны:
* **Маршруты (Routes)**:
  * Просмотр всех бэкендов и их выделенных портов.
  * Кнопка копирования адреса или готовой строчки `.env` в 1 клик.
  * Пинг целевого сервиса прямо из интерфейса.
  * Быстрое включение/отключение проксирования.
* **Инспектор трафика (Live Traffic Inspector)**:
  * История всех запросов в реальном времени через WebSocket.
  * Детальный просмотр заголовков запроса и ответа.
  * Подсветка внедренных CORS-заголовков и исправлений Cookie.
* **Playground**:
  * Встроенная интерактивная консоль для отправки тестовых запросов из браузера через выделенный прокси-порт.

## ⚙️ Структура проекта

* `server/` — ядро прокси на Node.js + Express + `http-proxy`:
  * `corsEngine.ts` — обработка preflight OPTIONS и эхо-отражение Origin.
  * `cookieEngine.ts` — нормализация `Set-Cookie` (снятие Secure, адаптация Domain, SameSite).
  * `proxyManager.ts` — динамическое выделение портов и жизненный цикл прокси.
  * `store.ts` — автосохранение настроек в `fetcher-config.json`.
  * `api.ts` — REST API управления + WebSocket сервер для трансляции трафика.
* `client/` — современный интерфейс на React + Vite + Vanilla CSS (Glassmorphism Dark Theme).
* `fetcher-config.json` — сохранённые конфигурации бэкендов.
